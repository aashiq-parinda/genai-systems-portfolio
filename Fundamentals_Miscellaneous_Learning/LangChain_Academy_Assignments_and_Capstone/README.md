# 🎓 LangChain Academy: Assignments & Capstone Mastery

Welcome to your dedicated hands-on workspace for **LangChain Academy** coursework, guided assignments, and the comprehensive **Capstone Project**.

## 🗺️ Learning Roadmap & Curriculum Structure

Each module is structured for **step-by-step interactive practice**: conceptual walkthrough $\rightarrow$ guided code implementation $\rightarrow$ hands-on assignment $\rightarrow$ verification.

| # | Module / Assignment Track | Core Concepts | Status |
|---|---------------------------|---------------|:------:|
| **01** | **Foundations: Agents & LangGraph Core** | Nodes, Edges, Graphs, Conditional Routing, Tool Calling | ⏳ In Progress |
| **02** | **State Schemas & Reducers** | `MessagesState`, Custom Schema, `Annotated[list, add_messages]`, Trimming | ⏹️ Queued |
| **03** | **Human-in-the-Loop (HITL)** | Dynamic Breakpoints (`interrupt()`), State Inspection & Overrides | ⏹️ Queued |
| **04** | **Persistence, Memory & Time Travel** | Checkpointers (`MemorySaver`, SQLite), Threads, Rewinding State | ⏹️ Queued |
| **05** | **Subgraphs & Multi-Agent Teams** | Supervisor Pattern, Specialized Workers, Message Passing | ⏹️ Queued |
| **🎓** | **Final Capstone Project** | End-to-end Autonomous Agent System with Memory, HITL & Multi-Tool Execution | ⏹️ Queued |

## 🛠️ Environment Setup

1. **Python Environment**: Managed via Python 3.13 / `uv`.
2. **Environment Variables**: Copy `.env.example` to `.env` and configure your API keys (OpenAI / Anthropic / LangSmith).
3. **Execution**: Every exercise includes standalone scripts and interactive checks so you can inspect state step-by-step.
